怎么核对官方价格

很多厂商的定价页是 JavaScript 渲染的，直接抓 HTML 拿不到价格表。但这批文档站同时提供 Markdown 原文：在页面 URL 后面加 .md，或先读站点的 llms.txt 索引，通常能直接拿到带价格的表格。本期以下厂商就是用这个方法核到官方的：

如何更新数据

所有数据维护都在一个命令入口里完成，不需要懂 Astro 或 TypeScript。命令细节见 node scripts/data/cli.mjs --help。

node scripts/data/cli.mjs rate      # 更新汇率（USD→CNY）
node scripts/data/cli.mjs pull      # 更新聚合补位数据
node scripts/data/cli.mjs add --provider deepseek --model deepseek-flash \
  --input 1 --output 4 --source-url https://api-docs.deepseek.com/zh-cn/quick_start/pricing \
  --verified-at 2026-10-31
node scripts/data/cli.mjs verify    # 交付前必跑：schema + 溯源完整性
node scripts/data/cli.mjs drift     # 本地官方值 vs 聚合值差异表（只报告）
node scripts/data/cli.mjs publish   # verify → typecheck → test → build → 部署

也可以使用 npm run data:rate、npm run data:pull、npm run data:verify、npm run data:drift、npm run data:add、npm run publish。

所有写文件的命令都先校验再落盘（临时文件 + 原子 rename）：非法输入被拒绝时，原文件一个字节都不会变。

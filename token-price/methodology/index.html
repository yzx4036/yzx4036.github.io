来源与核验

只采用厂商官方定价或文档页面，以及明确标注的第三方聚合源；不采用搜索摘要、媒体文章、中转商价格或模型记忆。当前官方条目核验日期为 2026-10-31，来源链接随每条记录展示。页面可访问不代表价格永久有效，使用前应再次查看官方页面。

溯源分级：official 与 aggregate

每条价格必须声明溯源等级：

  • official（官方核验）：人工打开厂商官方定价页，逐项核对输入价、输出价、缓存价与适用条件，页面标「官方核验 · 核验日期」。共 122 条。
  • aggregate（聚合数据）：取自第三方聚合源（models.dev），未逐条核对官方页，页面标「聚合数据 · 未逐条核官方 · 抓取于 YYYY-MM-DD」。共 46 条。

同一模型同时存在两种来源时以 official 为准，aggregate 只补空缺，绝不允许聚合值静默覆盖官方值。排行榜与「最便宜」类结论只基于 official 条目；官方样本不足时页面不给出结论。

为什么有些厂商仍只走聚合：很多定价页是 JavaScript 渲染的，但这批文档站同时提供 Markdown 原文——在页面 URL 后加 .md，或先读站点的 llms.txt 索引，就能直接拿到官方价格表。本期用这个方法核到官方的有 OpenAI、智谱、xAI、Mistral（以及 DeepSeek、MiniMax、Anthropic、Google）。仍只走聚合的是：Kimi、小米、阶跃、Cohere（其 Standard Vault 按实例小时计费，与 per-token 不可比）、Meta。这类厂商宁可标 aggregate 并注明，也不把推测写成 official。

国内厂商的聚合条目要额外说明一句：聚合源对国内厂商同样以 USD 发布，数值是按汇率从厂商人民币挂牌价折算来的。所以这些条目的账单币种是 CNY、报价币种是 USD，页面标「聚合数据 · 聚合源 USD 折算」，绝不标「官方原价」。

币种：账单币种决定主列，人民币只是估算副列

每条记录有三个概念，不能混用：

  • billingCurrency：厂商实际账单币种，这是账单真相，也是价格主列的币种。国内厂商为 CNY，国际厂商为 USD。
  • reportedCurrency：这条数字本身以什么币种表达。官方条目必须与账单币种一致；聚合条目由聚合源以 USD 发布，因此国内厂商的聚合条目是「账单 CNY + 报价 USD」。
  • 展示用人民币值：只在国际厂商行作为副行出现，由美元原价乘汇率得到，必须带「≈」与「估算」；国内厂商行不出现美元。

因此页面标注分四类：official + CNY 标「官方原价」，主列是人民币；official + USD 主列是美元原价，副行标「≈ ¥… · 按 6.6696 估算（2026-10-31）」，不出现「官方原价 ¥」这类写法；聚合 + 账单 CNY + 报价 USD 标「聚合数据 · 聚合源 USD 折算 · 汇率 …」，同样不出现「官方原价」字样；聚合 + USD 主列仍是美元原价，副行标聚合来源与估算人民币。schema 强制「official 条目的 reportedCurrency 必须等于 billingCurrency」，写错即校验失败。

排序不做跨币种合并：表格先按账单币种分组（美元组在前、人民币组在后），组内再按原币种价格升序，因此不存在一个把美元条目和人民币条目混在一起的「最便宜」榜首。

汇率口径

汇率来自 open.er-api.com，本次为 1 USD = 6.669566 CNY，汇率日期 2026-10-31，抓取时间 2026-11-01T00:06:56.870Z。页面只读 src/data/generated/fx.generated.json，文件缺失时构建直接失败；代码里没有把汇率写死成常量充当唯一来源。

汇率随时变化，人民币数值为按某日汇率估算的参考值，不准确；最终账单以厂商原币种为准。本站不承诺实时汇率，也不做跨币种套利或结算建议。缺汇率时美元原价照常展示，人民币位置明确写「汇率数据缺失」，不给 0，也不退回过期数值。

API 与 Plan 分开

API 是按使用量计费，Token/Coding Plan 通常还包含周期、额度语义、公平使用和用途限制。两者不进入同一个「最便宜」排行，也不把月费强行换算为每 1M Token。

计算公式与缺价

估算成本 = Σ（某类 Token 数量 ÷ 1,000,000 × 该类单价）。若某类用量大于 0，而对应价格为空，计算器会 fail closed，不输出部分总价。结果不含税费、缓存存储、搜索、工具调用及官方另行列示的费用。

峰谷价、阶梯价与批量价

DeepSeek 按请求时段区分峰谷价，本项目拆成独立条目并在模型名与口径里重复标明。阿里百炼、火山方舟、MiniMax 的部分模型按输入长度阶梯计价，本项目收录最低一档并在口径里写明其他档位价格；批量（Batch）、优先服务、长上下文溢价同样写在口径列，不用最低条件代表全部请求。

聚合源说明

聚合快照 2026-10-31T15:02:50.309Z，来自 models.dev（235 个 provider / 8930 个模型）。聚合条目的数字由聚合源以 USD 发布，可能与厂商官网人民币挂牌价不同；本站照抄聚合值并标注来源，人民币值只在估算副列出现，不回写数据、不修补聚合值。

数据更新方式

汇率、聚合快照、新增条目都由 scripts/data/cli.mjs 维护：rate / pull / add / verify / drift / publish。写文件命令一律先校验后原子落盘，非法输入不会污染数据文件。

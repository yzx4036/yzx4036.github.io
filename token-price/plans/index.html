共 55 档 · 缺价条目始终排在所属币种组末尾

国际版 标记的条目是同一厂商面向海外市场的独立品牌（例如智谱的 Z.AI、月之暗面的 kimi.ai）， 以美元挂牌、与国内站的同名套餐是两套互不通用的定价，不能直接比价。

部分不限量14 档存在真·不限量项，但天花板在别处。OpenAI 的日常文本对话四档都不限量，可最新的 GPT-6 全系连 Pro 档也只是「扩展额度」，反而是上一代 GPT-5.6 在 Pro 上才不限量；Copilot 与 CodeBuddy 则是代码补全不限量、对话与 agent 走积分或 Credits。其余 37 档为纯额度制，另有 4 档官方未披露数值；Claude 官方原话是 Every plan has usage limits。

折算可用 token 的口径。 22 档能算出数、33 档算不出（只给了定性描述或未公开换算率）。能出数的四档口径不同， 每行详情里写明了「计算假设」：官方货币锚定与按 $ 额度折算的，一律按 零缓存命中 + 标准时段价 + 输入输出 3:1 估算； 官方额度表那 6 档（智谱 / Z.AI）用的是官方给的区间中点，但官方区间本身 已含 98% 缓存命中假设，所以这几档相对其它档偏乐观，已在行内标注。 编码场景的缓存读单价通常远低于输入价，所以「零缓存」这一侧的估算会系统性偏低 —— 两组数字只能各自和同口径比，不能跨口径直接比大小。

为什么不按「最便宜」统一排名

订阅是按月买额度，不是按 Token 买量，所以不能和 API 单价混在一起比。同一档位在不同厂商之间的额度口径也不同（有的给请求次数、有的给积分、有的给 Credit），我们只如实呈现原价与额度语义，不替读者折算。

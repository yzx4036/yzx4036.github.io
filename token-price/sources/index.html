官方页价格怎么取到的

官方定价页大多是 JavaScript 渲染的，直接读 HTML 拿不到价格表。好在这批文档站同时提供 Markdown 原文（在页面地址后加 .md，或先读站点的 llms.txt 索引），通常能直接读到带价格的表格。以下厂商按此方式取到：

  • 智谱 GLMdocs.bigmodel.cn/cn/guide/start/pricing.mdCNY
  • Anthropicplatform.claude.com/docs/en/about-claude/pricingUSD
  • OpenAIplatform.openai.com/docs/pricing.mdUSD
  • xAIdocs.x.ai/docs/pricing.mdUSD
  • Mistraldocs.mistral.ai/inference/pricing/USD
  • DeepSeekapi-docs.deepseek.com/zh-cn/quick_start/pricingCNY
  • MiniMaxplatform.minimax.cn/docs/pricing/overviewCNY
  • Googleai.google.dev/gemini-api/docs/pricingUSD

取到官方页数字的条目标「官方页抓取」；取不到的保持「聚合数据」并标注「未核官方页」，两者不混算。官方页上由平台转售的第三方模型（例如 Mistral 页上的 Z.ai / DeepSeek）不属于该厂商自有模型，不记到该厂商名下。

数据怎么保持更新

脚本每天自动抓一次汇率、每周重抓一次聚合快照，另外自动重建派生数据、跑数据校验并记录官方价格历史快照，都由 GitHub Actions 定时触发；任何一条校验不过就放弃这次更新，不会把坏数据写进站点。官方页价格不在自动抓取之列——各家定价页改版频繁，机器判定容易误伤，这部分由维护者逐条人工录入，每条都带来源 URL 与抓取日期，入库前同样过数据校验；对这条链路，脚本只做差异比对，把官方值与聚合值偏差大的厂商挑出来复核。

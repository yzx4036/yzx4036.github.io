价格怎么核出来的

官方定价页大多是 JavaScript 渲染的，直接抓 HTML 拿不到价格表。好在这批文档站同时提供 Markdown 原文（在页面地址后加 .md，或先读站点的 llms.txt 索引），通常能直接读到带价格的表格。本期以下厂商就是这样核到的：

  • 智谱 GLMdocs.bigmodel.cn/cn/guide/start/pricing.mdCNY
  • Anthropicplatform.claude.com/docs/en/about-claude/pricingUSD
  • OpenAIplatform.openai.com/docs/pricing.mdUSD
  • xAIdocs.x.ai/docs/pricing.mdUSD
  • Mistraldocs.mistral.ai/inference/pricing/USD
  • DeepSeekapi-docs.deepseek.com/zh-cn/quick_start/pricingCNY
  • MiniMaxplatform.minimax.cn/docs/pricing/overviewCNY
  • Googleai.google.dev/gemini-api/docs/pricingUSD

核到官方数字的条目标「官方核验」；核不到的保持「聚合数据」并显式标注「未逐条核官方」，两者不会混着算。官方页上由平台转售的第三方模型（例如 Mistral 页上的 Z.ai / DeepSeek）不属于该厂商自有模型，不记到该厂商名下。

数据怎么保持更新

写了个脚本定时更新：汇率每天自动抓一次，聚合快照每周重抓一次，都由 GitHub Actions 定时触发。抓完先跑一遍数据校验，任何一条不过就放弃这次更新，不会把坏数据写进站点。

官方价格不走自动抓取——各家定价页改版频繁，机器判定容易误伤，所以这部分保持人工核对后入库。脚本会定期比对官方值与聚合值的差异，差异大的厂商会被挑出来人工复核。

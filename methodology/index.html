这里解释一个数字为何出现、何时失效，以及哪些成本没有被它覆盖。

来源与核验

只采用厂商官方定价或文档页面，不采用搜索摘要、媒体文章、中转商价格或模型记忆。当前数据于 2026-10-31 人工核验；来源链接随每条记录展示。页面可访问不代表价格永久有效，使用前应再次查看官方页面。

API 与 Plan 分开

API 是按使用量计费，Token/Coding Plan 通常还包含周期、额度语义、公平使用和用途限制。两者不进入同一个“最便宜”排行，也不把月费强行换算为每 1M Token。

计算公式与缺价

估算成本 = Σ（某类 Token 数量 ÷ 1,000,000 × 该类单价）。若某类用量大于 0，而对应价格为空，计算器会 fail closed，不输出部分总价。结果不含税费、缓存存储、搜索、工具调用及官方另行列示的费用。

峰值与低谷

DeepSeek 当前官方页面按请求发生时段区分峰值与低谷价。本项目将两种时段拆成独立条目，并在模型名、口径和计算结果中重复标明，避免用低谷价格暗示全天成本。

币种与汇率

所有现有价格均以 USD 展示。本版不提供 CNY 换算，因此也没有把固定汇率冒充实时汇率的风险。
